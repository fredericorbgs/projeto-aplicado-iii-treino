# Código

`fitrec_poc.py` lê o recorte filtrado do FitRec em fluxo, monta a matriz usuário–modalidade e calcula a vizinhança de itens, o hábito, a popularidade, o aleatório e a soma do hábito com a vizinhança.

O arquivo de cerca de 4,9 GB não entra no repositório. O script busca o endereço público da página do dataset e não grava o JSON. A saída são os dois arquivos de métricas, ao lado do script.

Biblioteca usada: Python 3 e numpy.
